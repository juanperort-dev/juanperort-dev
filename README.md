## Proyectos propios

### 🌤 WeatherApp
App de meteorología construida en Swift 6 con arquitectura de capas real (Domain, Data, Presentation).
Integra OpenWeather API via REST, SwiftData para persistencia, widgets con WidgetKit, visualizaciones con
Swift Charts y cobertura de tests completa con SwiftTesting.

Demuestra: Clean Architecture en producción propia, Swift 6 Concurrency, APIs modernas de Apple.

`Swift 6` `SwiftUI` `SwiftData` `WidgetKit` `Swift Charts` `SwiftTesting` `CoreLocation`
👉 [Ver en GitHub](https://github.com/juanperort-dev/WeatherApp)

---

### 🐾 PetBooker
App iOS de reservas para mascotas con backend real en producción: Firebase Firestore, Auth y Storage.
Incluye Google Sign-In, notificaciones push via FCM y gestión segura de credenciales con Config.xcconfig.

Demuestra: integración con servicios backend reales, autenticación, notificaciones push y seguridad en iOS.

`Swift` `SwiftUI` `Firebase` `Firestore` `Firebase Auth` `FCM` `Google Sign-In` `XCTest`
👉 [Ver en GitHub](https://github.com/juanperort-dev/PetBooker)

---

### 📍 MapApp
App de exploración de ubicaciones construida para profundizar en MapKit con arquitectura MVVM modular.
Marcadores personalizados, selección táctil de puntos de interés y navegación fluida entre vistas.

Demuestra: dominio de MapKit, estructura MVVM limpia y separación correcta de responsabilidades.

`Swift` `SwiftUI` `MapKit` `MVVM`
👉 [Ver en GitHub](https://github.com/juanperort-dev/MapApp)
